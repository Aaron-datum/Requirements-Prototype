# Decisions: requirements and traceability (Phase 6)

Assumptions made without blocking. Each default is behind config where possible (`src/fixtures/extras/requirements/`, `src/features/create/requirements/vocab.ts`). The shared decisions log (`docs/05-decisions-log.md`) was not edited.

| ID | Question | Default built | Where |
|---|---|---|---|
| R-01 | Which requirements need test mapping on 05? | Those not auto-accepted: text and Driven by not both Unchanged, or confidence under `thresholds.autoAcceptAt` (90). That is 8 of 16. The other 8 are the "mapped at >= 90% and accepted automatically" line. | `derive.ts` (`autoAccept`), MappingScreen |
| R-02 | Bulk "Accept all >= N" | Never accepts a requirement whose text is New or Changed (`matchRules.changedRaw`), a dangerous case, or a row with no score. | R-03 | Which flagged items are Undetermined vs Evaluated Elsewhere (06)? | Flagged = Si test run still Scheduled or In progress (six). | R-04 | Two confidences (D-07) | "Transfer confidence" is the test-link match confidence; "Computed confidence" is the Driven-by score. In the dataset they are equal for the two Evaluated Elsewhere rows; they are labelled differently with a why popover everywhere. | `ConfidencePair` |
| R-05 | Driven-by interface entity | None in the dataset. `extras/requirements/interfaces.ts` assigns an interface id per requirement; "Confirm Changed" propagates to every Changed requirement sharing that id (REC-20001 + 20008, REC-20004 + 20016, others alone). | `sharingInterface` |
| R-06 | Does confirming clear the dangerous-case highlight? | The condition stays derived (Text Unchanged and Driven by Changed, still listed as dangerous). | R-07 | Plan receipt counters | Every requirement lands in exactly one of Carried (auto, or evidence linked), Routed (accepted mapping, or moved to Gap) or Still open; the three always add up to the total. Open reasons: evidence not linked, mapping rejected, mapping not reviewed. | `planSummary` |

| R-09 | Acknowledgement | Always required, even with zero open requirements (the label adapts). | ApproveScreen |

| R-11 | Evidence store | Eight hard-coded records.
